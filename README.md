# Candid

Candid is a Fabric film-photography mod for Minecraft Java Edition, designed around a compact 35 mm rangefinder camera, exposure controls, physical film rolls, darkroom processing, and displayable photographs.

## Target
- Minecraft Java 1.21.10
- Fabric Loader 0.19.5
- Fabric API 0.138.4+1.21.10
- Java 21
- Single-player / integrated server first
- Steam Deck-friendly controls

## Design goals
- Craftable rangefinder-style camera
- 36-exposure film rolls
- ISO 100 / 200 / 400 / 800 stocks
- Aperture + shutter speed controls
- Live reflected light meter in the viewfinder
- Film-stock looks inspired by classic daylight, portrait, consumer-gold, and high-speed color-negative emulsions
- Exposed-roll -> developing tank -> negatives -> contact sheet / print workflow
- Displayable photographs
- Creative-mode Candid guidebook
- Recipes that are affordable enough for normal survival play
- No dependency on a Paper server

See the in-game Candid Guide for the actual play loop once the mod is installed.
